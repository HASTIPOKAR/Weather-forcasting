About WeatherCast

A full-stack weather forecasting application demonstrating modern web development technologies and best practices.

🌤️

What is WeatherCast?

WeatherCast is a web-based weather application that allows users to search for any city and view comprehensive weather information including temperature, weather conditions, humidity, wind speed, atmospheric pressure, weather icons, and a multi-day forecast.

The application features user registration and login, search history tracking, favourite cities management, and a responsive design that works seamlessly across all devices.

🎯

Project Objectives

  • Develop a user-friendly weather forecasting website
  • Allow users to search weather by city name
  • Display real-time current weather information
  • Show temperature, humidity, wind speed, pressure, and conditions
  • Display appropriate weather icons
  • Provide a multi-day weather forecast
  • Implement user registration and login system
  • Maintain search history for logged-in users
  • Provide a favourite-city feature
  • Create a responsive website for all screen sizes
💻

Technology Stack

WeatherCast demonstrates integration of multiple web technologies working together as a full-stack application.

HTML5 CSS3 JavaScript PHP MySQL OpenWeather API Apache / XAMPP Responsive Design
🏗️

System Architecture

The frontend provides an interactive and responsive interface using HTML, CSS, and JavaScript. JavaScript communicates with the OpenWeather API to fetch live weather data and dynamically updates the page.

PHP handles server-side operations including user authentication, search history, and favourite cities. MySQL stores all persistent application data including user accounts, search records, and favourite city lists.

⚡

Key Features

  • Real-time weather data from OpenWeather API
  • Current weather with detailed metrics
  • 5-day weather forecast
  • City search with validation
  • User registration with secure password hashing
  • Login/logout with PHP sessions
  • Search history tracking
  • Favourite cities management
  • Responsive design for all devices
  • Error handling and user feedback
